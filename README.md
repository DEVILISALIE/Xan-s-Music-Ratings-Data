# Xan's Music Ratings Desktop

一个专为个人长期收藏打造的 Windows 音乐评分与乐评管理软件。

它不是播放音乐的听歌软件，也不是在线搜索匹配评分的数据社区，而是一份完完全全属于你自己的**私人音乐档案库**。

就像一本专为你定制的数字音乐手账：本软件不提供在线音频流媒体，也不会自动联网抓取数据；所有的专辑、单曲、分数、长篇短评以及高清封面，都由你自己亲手录入、整理并保存在本地电脑中（也支持通过纯文本格式批量导入）。安安心心，完全由你掌控。

无论你是习惯在听完一张新唱片后随手记下几笔听感，还是在每年年末认真评出自己的年度最佳（AOTY / SOTY）并写下长篇小作文，亦或是想把几十年来听过的上千张唱片按年代整理成册，它都能为你提供一个专注、纯粹且极具质感的私人记录空间。

这里没有流媒体突如其来的下架变动，也没有社交网络的算法噪音与数据绑架。所有内容完全离线保存在你的本地电脑中，无需联网，打开即用。从细致到每首歌的逐曲打分与多碟管理，到纵跨数十年的全盘统计与走势图表，它会为你安安静静沉淀出一张独一无二的私人音乐编年史。

## 把几十年的音乐放在同一张时间轴上

左侧用年代与年份把所有专辑和单曲整理得井井有条，中间展示每一年的音乐卡片，右侧则实时汇总你的整体评分分布。即使收藏了上千张唱片，点击左侧侧边栏也能瞬间跳转到对应的年份，滚动时导航高亮会自动跟手同步。

不同年代支持智能排序：新专辑按发行日期排序，老唱片按年份倒序排好，年度最佳（AOTY/SOTY）永远稳居最前面。每张卡片上清晰标有评分、发行时间、自定义标签、曲目数量以及高分必听（★Must Hear）徽标，翻看时一目了然。

## 纯本地存储，数据安全无忧

你的所有音乐评分与心血乐评均存放在本机电脑中：

```text
%APPDATA%\com.xan.music-ratings\music-data.json
```

本地封面与缩略图保存在：

```text
%APPDATA%\com.xan.music-ratings\covers\
```

- **数据掌握在自己手中**：不依赖任何第三方服务器或云端账户，完全离线可用。
- **自动备份防意外**：每次保存修改前，软件会自动生成一份 `.json.bak` 备份文件；若检测到主文件异常会自动尝试从备份中恢复。
- **退出安全保护**：退出程序时会等待数据完整写入磁盘后再关闭窗口，避免中途断电或意外退出导致数据损坏。
- **随时导出备份**：软件左下角提供“导出 JSON”按钮，建议定期将数据文件备份到移动硬盘或网盘中，十年心血历久弥新。

## 开发者与编译构建

如果你需要自行构建源码，需要本地已安装 Node.js、Rust 编译工具链与 Visual Studio C++ 生成工具。

```bash
# 安装前端依赖
npm install

# 启动本地开发调试
npm run tauri dev

# 编译正式版安装包（生成位于 src-tauri/target/release/）
npm run tauri build
```

## 从文本文件导入历史数据

如果你原本在普通的 txt 文本中整理了乐评，可以使用内置的转换器一键解析生成：

```bash
node gen.js
node gen.js 你的文本文件路径.txt
```

解析器会自动将格式规范的纯文本转换为结构化音乐档案，并自动把 `Vol. N - YYYY` 等形式的合集归入对应年份。
